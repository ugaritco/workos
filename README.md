## Introduction

These Ugarit WorkOS utilities are used by the [Ugarit starter kits](https://ugarit.com/docs/starter-kits) to integrate with [WorkOS AuthKit](https://www.authkit.com/).

## Official Documentation

Documentation for our starter kits can be found on the [Ugarit website](https://ugarit.com/docs/starter-kits).
